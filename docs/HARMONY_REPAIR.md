# 소울 디스코 화성 수리

대상은 Phase 3에서 실제 편곡·믹싱한 116 BPM 소울 세션의 마지막 저장본 `03-keys`다. 원본 MIDI와 WAV를 보관하고 같은 샘플 매핑·믹서로 별도 세션을 렌더했다.

| 기존 세션의 후보 | 확인 및 수정 |
|---|---|
| Music Plan과 마디 코드 | 네 코드 요약을 문자 그대로 반복하면 실제 차트의 12개 마디와 달랐다. 인트로와 종지에 이미 의도한 마디별 코드를 명시했고, 새로 쓰는 악보와 프로젝트 마커는 같은 진행을 읽는다. |
| 지속되는 반음 3건 | 7마디 12.678초·13.713초, 11마디 20.954초에 E4(64)와 F4(65)가 0.46~0.58초 겹쳤다. F4를 F3로 내리고 E4는 남겨 Dm9의 단3도와 9음을 모두 보존했다. |
| 건반·기타 같은 음역 중복 36쌍 | 기타가 건반 상성부 세 음을 복사했다. 짧은 상성부 단음으로 바꾸고, 기존에 쉬도록 편집한 마디와 연주 시점을 보존했다. 같은 음을 여러 악기가 연주하는 것은 곡에 따라 의도적인 선택일 수 있다. |
| 마지막 코드 중복 4음 | 14마디 같은 위치에서 같은 네 음에 두 번 note-on이 발생했다. 긴 종지 코드를 유지하고 짧은 중복 이벤트를 음소거했다. |
| 베이스와 릴리스 | 수정 후 해결되지 않은 강박 비화성음은 0건이다. 마디선에서 MIDI 음이 끝난 뒤 베이스의 릴리스만 겹치는 곳 10건은 별도로 기록했다. |

단음 측정에는 원본 77개, 수정본 53개 음정·샘플 조합을 사용했다. 기준 A4는 440Hz다. 원본의 실측 REAPER 음정은 목표 음에서 최대 7.17센트, 수정본은 최대 10.12센트 벗어났다. 같은 음에 대한 REAPER와 Python의 차이는 양쪽 모두 최대 0.08센트였다. 녹음 원음과 SFZ 오프셋을 유지했다.

수정 전후 자동 검사 후보는 55건에서 0건으로 줄었다. 동일 길이 두 마스터의 차 신호 RMS는 −34.98 dBFS였다. 세부 기록에는 마디·트랙·음정·시각과 겹침 길이가 포함된다. 배포 폴더의 `soul-before.json` 및 `soul-after.json`에서 확인할 수 있다. 보이싱 수리는 이 저장본의 패턴에 한정한다.

원본 세션을 가진 환경에서는 다음 명령으로 별도 수정본을 만든다.

```sh
.venv/bin/python -m engine.daw.produce --repair-soul outputs/daw-session/03-keys/session.json --out outputs/repaired-soul-new
```
