# IRON RETURN · Heavy Alternative Instrumental

D minor, 108 BPM, 4/4, 48마디. 도입의 짧은 저음 D 리프가 마지막에 풀 밴드로 돌아온다. 27마디부터 리드가 D–F–A를 길게 당기는 동안 킥과 베이스가 계속 움직인다. 35마디에서 기타와 공간 리턴이 함께 사라지면 하강하는 베이스와 하프타임 드럼이 네 마디를 채운다.

[최종 MP3](../examples/v61/iron-return-master.mp3) · [최종 24-bit WAV](../examples/v61/iron-return-master.wav) · [새 YuE2 원본 float WAV](../examples/v61/iron-return-original.wav) · [오디오 포함 REAPER 프로젝트](../examples/v61/iron-return-reaper.zip)

ZIP을 풀고 `Iron Return.RPP`를 열면 된다. 재생에는 REAPER 기본 이펙트와 번들 앰프 응답 파일이 필요하다. 활성 트랙은 무손실 오디오이며 뮤트된 참고 트랙에는 용량을 줄인 MP3를 넣었다. 로컬 제작 세션과 별도 배포 원본에는 원래 float WAV가 있다. ZIP 안에 트랙별 음표·타격 시각, 소스 편집 내역, 실제 FX 설정도 담았다.

## V6 진단과 새 소스

기존 V6에서 기계음과 신스를 제외하고 기타·드럼·베이스 추정 트랙을 검사했다. 솔로 구간의 드럼은 −90.81 dBFS RMS, 베이스는 −93.89 dBFS였다. 같은 소스의 마지막 확장에서는 각각 −16.91, −17.40 dBFS였다. 솔로에서 반주가 거의 빠져 있었다. 새 곡에서는 기타 솔로와 리듬 섹션을 함께 작곡했다.

공식 YuE2 연주곡 검증기가 48마디, 192박, 기악 음표 165개, 보컬 음표 0개를 읽었다. 모델에 전달한 ABC와 생성기가 기록한 악보가 일치했다. 확장 화음의 음은 기악 성부에도 나누어 썼고 파워 코드는 루트와 5도를 썼다. YuE2-3B Q8, F32 VAE, Metal, Full CoT, 32단계로 생성했다. 첫 테이크는 원본과 음성 추정치 양쪽에서 같은 영어 가사 조각이 반복 인식되어 제외했다. 채택한 seed 57은 426.6초와 최대 4.15 GiB를 썼다. 원본은 110초 상한에서 종료됐다. 종지는 후속 편곡에서 만들었다. [실행 기록](../examples/v61/generation.json) · [공식 입력 검증기](https://github.com/multimodal-art-projection/YuE/blob/1116bea76032bee5668e5f097294d082fa0b84f0/skills/yue2-music/instrumental/scripts/instrumental.py)

채택 원본의 음성 추정 RMS는 두 모델에서 전체보다 43.4 dB, 33.3 dB 낮았다. 첫 6초의 음성 판별 신뢰도가 낮아 원본과 분리 추정치를 각각 전사했다. 두 전사는 서로 다른 상투 문구를 냈다. 짧은 음성 유사음에 대한 청취 판단은 열어 둔다. 마스터에 가사, 보컬 트랙, 생성 원본 전체 믹스를 넣은 구간은 없다. [음성 검사](../examples/v61/voice-screen.json)

생성 드럼에서 71.6·143.3 BPM 주기도 강하게 검출됐다. 107.5 BPM 후보와 점음표 관계를 함께 고려해서 107.69 BPM 격자에서 마디 경계를 추정하고, 각 조각을 108 BPM에 맞췄다. 기타 추정 트랙은 음고 분포와 코드가 맞는 조각을 골라 최대 두 반음 이동했다. 드럼의 실제 강세와 기타의 모든 화음을 자동으로 전사한 것은 아니다. 브리지에는 생성 스템을 하나도 넣지 않았다. [사용한 소스 마디·속도·피치](../examples/v61/edits.json)

## 악기와 실제 프로세싱

- 좌우 리듬 기타는 Emilyguitar의 서로 다른 피킹 샘플, 보이싱, 타격 위치와 감쇠 길이로 연주했다. 이중 라이브 테이크의 미세 타이밍까지 재현되지는 않는다. 저음 뮤트는 피킹 샘플의 감쇠와 필터로 만들었다. 중앙 리드는 별도 악보를 연주하며 벤딩은 재생 속도와 비브라토 곡선으로 제어한다.
- REAPER에서 기타 세 트랙 각각에 드라이브, 컨볼루션 앰프·캐비닛, ReaEQ를 로드했다. 좌측은 JCM800 / Marshall Stock 70, 우측은 JCM800 / Matchless Chieftain, 리드는 JTM45 / Matchless Chieftain이다. 드라이브는 각각 28·25·31 dB다. 비선형 드라이브와 선형 IR의 조합이다. NAM은 해당 호스트에서 발견되지 않았다. 번들 IR은 사용자의 REAPER 설치본에서 불러온다. [호스트가 반환한 파라미터](../examples/v61/fx.tsv) · [Neural Amp Modeler](https://www.neuralampmodeler.com/the-code)
- Fashionbass와 Virtuosity Drums의 녹음 샘플로 독립 베이스와 드럼을 연주했다. 킥과 두 기타의 주요 강세는 맞추고 베이스 연결음, 고스트 스네어, 탐·심벌 타격은 별도로 배치했다. ReaComp는 킥·스네어의 앞부분이 통과하도록 킷에 23 ms 어택을 썼다.
- 스크래치는 새 기타 어택을 왕복하는 가상 플래터와 크로스페이더로 연주했다. 0.69초, 49.31초, 56.39초에 등장한다. CC0 금속 파이프는 1.67초와 52.78초 두 번이다. 타자기·모터 반복은 없다. [녹음 출처·IR 해시·실제 큐](../examples/v61/sources-and-cues.json)
- 드럼에는 짧은 룸을, 기타에는 저역을 정리한 긴 홀과 스테레오 코러스를 보냈다. 리드의 점8분음표 딜레이는 목표 416.7 ms, 호스트 표시 416.6 ms이며 피드백은 −8.5 dB다. 홀·딜레이·룸이 솔로 끝에서 닫혔다가 마지막 리프 뒤에서 열린다. 실제 스피커 앞에서 녹음한 피드백은 사용하지 않았다.

## 마스터에서 검증한 변화

- 기타·드럼·베이스를 각각 REAPER에서 따로 출력했다. 솔로 여덟 마디의 마디별 RMS는 리드 −26.05~−23.74, 드럼 −28.91~−27.59, 베이스 −29.78~−27.92 dBFS였다. 리드 단독 오디오에서 27·28·29·31·33마디의 벤딩 다섯 개가 1.31~1.48반음 상승해 목표음에서 0.2반음 안으로 들어왔다. 30·34마디 끝에는 킷 필이 있다.
- 브리지 4마디 전체에서 기타 단독 출력의 최대 샘플 값은 0이었다. 전체 마스터에서 베이스·드럼만 렌더한 출력을 뺀 값도 전 샘플에서 0이었다. 브리지의 RMS는 −27.17 dBFS, 전체 밴드가 다시 들어오는 39–42마디는 −18.32 dBFS, 43–46마디는 −17.99 dBFS다.
- 베이스·컴핑·리드 이벤트에서 지속적인 동일 음역 반음 충돌을 검사했다. 지정한 일곱 전환에서 베이스 C♯이 다음 D로 한 반음 올라간다. 렌더의 베이스를 따로 분석해 브리지의 D–C–B♭–A 및 45→46마디의 C♯→D 음급을 확인했다. 저음에서 두 번째 배음으로 잡힌 경우가 있어 옥타브 판정은 유보했다.
- 48 kHz, stereo, 24-bit PCM, 108.317초. −18.80 LUFS, −1.60 dBTP, 클리핑 0샘플, 크레스트 팩터 19.56 dB, 모노 합산 변화 −0.43 dB. 6개 구간 경계의 이웃 샘플 간 변화는 0.00010~0.00685였고 각각 인접한 20 ms의 최대 변화보다 작았다. 킥과 베이스의 청감상 마스킹이나 미세 클릭 전부를 이 수치로 배제할 수는 없다.
- 원래 WAV 프로젝트와 배포용 무손실 미디어 프로젝트를 별도로 열어 렌더했다. 모두 최종 마스터의 24비트 PCM과 일치했다. 저장소 자동 테스트 65개가 통과했다. 기존 설정 모듈의 Pydantic 경고 한 건이 있었다. 장르의 공격성, 피킹의 자연스러움, 솔로의 정서적 설득력은 사람의 청취 평가가 남아 있다. [악기별 측정·구간 에너지·오디오 검사](../examples/v61/qa.json)

## 재현

듣거나 기존 프로젝트를 열 때는 모델이나 샘플 다운로드가 필요하지 않다. 새로 제작할 때는 V5의 로컬 모델·분리기 및 REAPER 설정을 사용한다. 다음 명령은 저장소 루트에서 실행하며 편집 출력을 새 디렉터리에 쓴다. [모델·호스트 환경](V5_METALLIC_DREAM.md)

```sh
.venv/bin/python -m engine.session.bank
.venv/bin/python -m scripts.heavy.score
.venv/bin/python -m scripts.v5_stems examples/v61/iron-return-original.wav outputs/v61/repro-stems
.venv/bin/python -m scripts.heavy.mix examples/v61/iron-return-original.wav outputs/v61/repro-stems/htdemucs_6s outputs/v61/repro-studio
.venv/bin/python -m scripts.heavy.verify outputs/v61/repro-studio
.venv/bin/python -m scripts.heavy.package outputs/v61/repro-studio outputs/v61/repro-studio.zip
.venv/bin/python -m pytest -q
```

새 YuE2 생성은 `.venv/bin/python -m scripts.heavy.score --generate --seed 57 --instrumental-trio`로 실행한다. 새 테이크의 원본과 스템 폴더는 서로 맞춰서 사용한다.
