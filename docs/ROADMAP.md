# ROADMAP.md — AI-Native DAW Product Roadmap

| Phase | Name | Focus | Status |
|---|---|---|---|
| **Phase 01** | **Workspace Foundation** | Local-first DAW shell, Arrangement Timeline, Audio/Stem/MIDI tracks, Web Audio playback, Mixer, Clip Editor, Piano Roll, Undo/Redo, Persistence, Stereo WAV Export, Multi-Agent Foundation | **In Progress** |
| **Phase 02** | Reference Intelligence | Reference audio analysis (BPM, harmony, rhythm, instrumentation, structure, energy, timbre), Reference Blueprint, A/B comparison | Planned |
| **Phase 03** | AI Composition | Natural-language generation, YuE2 native adapter, ACE-Step adapter, single-instrument/MIDI/loop generation, stem separation, timeline auto-placement | Planned |
| **Phase 04** | AI Arrangement | Selection-scoped natural-language commands (e.g. "vary guitar bars 9–16"), takes, A/B diff, approve/restore | Planned |
| **Phase 05** | Sound Design | Virtual instruments, synth, sampler, AU/VST3 hosting (via REAPER/native bridge), EQ/Comp/Delay/Reverb/Distortion/Modulation FX Rack, automation | Planned |
| **Phase 06** | Mixing & Mastering | Track auto-mixing, spatial buses, sidechain, reference matching, mastering, acoustic QA | Planned |
| **Phase 07** | Full Music Production | 3–4 minute full songs, musical themes & lyrics, optional vocals, vocal editing, master & stem export | Planned |
